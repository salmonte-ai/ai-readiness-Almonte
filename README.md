For this exercise I used the following three commands, git add, git commit, and git push. 
The git add command is used when you want to select files you want added to the repository. 
The git commit command takes the files from what essentially a staging area and saves it.
In conjuction with that command,the "-m" is used to add a description to the files being added.
FInally, the git push command sends the files to the repository.
